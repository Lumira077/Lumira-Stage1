# R4 10DOF — 가정·사무실 자율주행 추가

2026-10-26 · 주행 판단/경로 추종 소프트웨어 및 2D 검토 시뮬레이션

## 구현 범위

R4의 10개 상체 관절과 별도로 좌우 구동 바퀴 2개를 사용하는 차동구동을 전제로 합니다. 이번 구현은 혼자 이동/사용자 동행의 상태 판단, 격자 지도 A* 경로 계획, 장애물 여유 공간 반영, 경로 추종 속도 계산, 대상 분실·접촉·센서 장애 시 정지를 실행하는 **오프라인 시뮬레이터**입니다. 실물 센서 수집, SLAM, 사람 추적기, ROS/Nav2 실행, 모터 통신은 아직 연결하지 않았습니다.

## 혼자 움직이는 경우

|상황|시작 조건|판단·실행|종료|
|---|---|---|---|
|지정 장소 이동|사용자가 앱/음성으로 등록 목적지 선택|위치·지도·센서·팔 접힘 확인 → 경로 계획 → 이동|도착 후 정지|
|사용자 호출|사용자 또는 앱이 유효한 호출 위치 제공|호출 지점 앞의 접근 위치까지 이동|사용자 가까이에서 정지·교감 전환|
|복귀|복귀 명령과 등록된 대기 위치|안전 경로로 대기 위치 이동|정지|
|충전 복귀|추후 배터리 기준과 충전 접근점 등록 필요|충전기 앞 접근점 이동까지 목표 이동 기능 사용 가능|자동 도킹·충전 접촉은 미구현|
|지정 순찰|사용자가 구간·운영 조건을 명시한 경우|복수 등록 목표를 순서대로 호출하는 상위 임무 관리 필요|순찰 스케줄러는 미구현|

현재 코드가 직접 구현한 것은 단일 목적지 이동입니다. 호출·복귀는 상위 시스템이 좌표를 제공하면 같은 경로 계획 기능으로 실행하는 구조입니다. 로봇이 사람의 부재나 움직임을 보고 임의로 돌아다니도록 설정하지 않습니다. 지도 없는 구역·주행 금지 구역은 통과시키지 않는 지도 구성이 필요합니다.

## 사용자와 같이 움직이는 경우

- 앱 또는 명시적인 “따라와” 명령으로 **특정 추적 대상 ID를 선택**한 뒤 시작합니다. 사람이 걸었다는 이유만으로 따라가기 모드에 들어가지 않습니다.
- 실제 구현에서는 RGB-D 카메라의 사람 검출·추적과 깊이/라이다 거리를 결합하여 대상 위치를 산출해야 합니다. 시뮬레이션은 이 융합 결과를 합성 입력으로 받습니다.
- 시험 목표 간격은 약 1.2m입니다. 너무 가까우면 정지하며, 뒤로 물러나는 기능은 기본 구현하지 않았습니다. 3m를 넘거나 대상 신호가 0.3초 이상 오래되면 정지·재확인 상태로 갑니다.
- 목표가 가구 반대편에 있으면 직선으로 따라가지 않고 지도 경로를 따라 목표 뒤쪽 접근점을 계산합니다.
- 다른 사람의 추적 ID는 따라가지 않습니다. 대상이 재등장해도 자동 재개하지 않고 `resume_follow` 또는 새 따라가기 명령을 요구합니다.
- **손을 잡은 채 걷기**는 이번 동행 모드에 포함하지 않습니다. 손 잡힘 입력이 들어오면 주행 임무를 취소하고 정지·교감 모드로 전환합니다. 팔 순응 제어와 사람 보행 안정성을 검증하기 전에는 손을 끌고 이동하지 않습니다.

## 하체 센서 보강안

아래는 센서 구성·장착 방향 제안이며 모델에 센서 실물과 체결부를 제작한 것은 아닙니다.

|장치|수량 초안|위치·역할|
|2D LiDAR|1|하체 고정 프레임, 가구·벽·통로 인지와 지도/위치 추정. 외피·팔·바퀴가 스캔을 가리는지 확인하고 필요하면 후방 보완|
|고정 RGB-D 카메라|1|몸통/하체 전면, 사람 추적·거리와 LiDAR 높이 밖의 장애물 보완|
|단거리 ToF|6|전방 좌/중/우 + 후방 좌/중/우, 근거리·낮은 장애물 보완|
|바닥 방향 낙하 센서|4|하체 앞좌·앞우·뒤좌·뒤우, 계단/탁자 가장자리 검출|
|접촉 범퍼|전후·측면 영역|근접 센서의 미검출을 보완하는 접촉 정지 입력|
|휠 엔코더|좌우 각 1|실제 바퀴 회전량·속도 피드백|
|IMU|1|하체 중앙의 강성 프레임, 회전·기울기/진동 정보|
|손 터치·압력|양손|교감 입력과 주행 정지 연동|

머리 카메라는 고개가 회전하므로, 주행 좌표계에 쓰려면 목 각도를 포함한 실시간 외부 파라미터가 필요합니다. 주행용 RGB-D는 몸체에 고정하고 기존 머리 카메라는 교감용으로 유지하는 구성을 우선 검토합니다. 기존 Haar 얼굴 방향 예제는 안정적인 사람 추적 성능이 검증되지 않았으므로 자율주행 사람 위치 입력으로 직접 사용하지 않습니다.

유리·검은 물체·직사광·얇은 의자 다리·케이블·카펫·반려동물은 센서 하나로 모두 검출할 수 있다고 가정하지 않습니다. 센서 사각지대와 바닥 반사 특성을 실측해야 합니다. 하체를 7.5% 줄였으므로 새 센서·배선·엔코더·배터리가 들어가는지 내부 배치를 다시 확인해야 합니다.

## 판단 우선순위

1. 비상정지 / 낙하 / 범퍼 / 카메라 위험 / 위치·인식 장애 → 정지 래치. 정상화만으로 재시작하지 않고 명시적인 reset 후 새 임무를 받습니다.
2. 손 잡힘 / 팔 미접힘 → 임무 취소·정지. 손을 놓아도 자동 주행하지 않습니다.
3. 따라가기 대상 분실·변경·거리 초과 → 정지·재확인 대기.
4. 경로 없음·목표가 장애물 안에 있음 → 정지. 지도가 갱신되면 다시 경로를 평가합니다.
5. 조건 정상 + 명시적 임무 → 목적지 이동 또는 따라가기.
6. 임무 없음·도착 → 대기.

교감 모듈과 주행 모듈의 출력을 한 모터 토픽에 따로 보내면 안 됩니다. 포함한 coordinator.py는 교감의 손 접촉/정지 요청을 주행의 `hands_held`/정지 입력으로 우선 반영하고 최종 바퀴 명령은 하나의 중재부에서만 내보내야 합니다. 시뮬레이터는 실제 모터 출력이 항상 false입니다.

## 시험 설정과 한계

가정/사무실의 임의 10×8m 지도, 0.1m 격자, 로봇 외접 원 반경 0.27m(팔을 접은 상태의 시험 가정), 최대 전진 0.20m/s, 회전 0.60rad/s, 계산 간격 0.1초입니다. 지도 장애물은 로봇 크기와 격자 오차만큼 부풀려 계획합니다. 바퀴 중심 간격 초안은 약 0.3339m이며 실제 타이어 접지 중심·유효 반지름과 엔코더 분해능을 측정해야 합니다. 바퀴 반지름 미설정 시 바퀴 각속도 변환 함수는 실행을 거부합니다.

이 모델은 속도 명령대로 즉시 움직이고 멈추는 **운동학적 시뮬레이션**입니다. 질량·관성·미끄러짐·제동 지연·전도·문턱 통과를 검증하지 않습니다. 실제 속도/가속도/제동 거리, 안정성, 접촉력이 검증되기 전 이 숫자를 실물 안전 한계로 사용하면 안 됩니다. 실제 운용에는 속도 완화, 충돌 감시, MCU 통신 watchdog, 하드웨어 비상정지가 필요합니다.

영상은 가정 단독/가정 따라가기/사무실 단독/사무실 따라가기 네 장면을 동시에 보여 줍니다. 따라가기에는 18–24초의 대상 분실과 24초의 명시적 재개 입력이 포함됩니다. 사람 좌표와 센서 정상 신호는 합성 데이터이며 실제 카메라로 추적한 영상이 아닙니다. 동적 장애물의 목표 차단 정지는 별도 단위시험으로 확인하고, 군중 회피 성능을 시험한 것은 아닙니다.

## 실행

루트 requirements.txt 설치 후:

```text
python navigation/src/test_navigation.py
python navigation/src/test_coordinator.py
python navigation/src/simulate.py
```

결과: `navigation/results/summary.json`, `scenarios.json`, `navigation/videos/R4_10DOF_Navigation_Simulation.mp4`. 지도·속도·목표는 시험 코드의 명시적 값이며 실제 집/사무실 지도와 다릅니다.

## 실제 로봇 통합 방향

Nav2의 경로 계획/제어, 속도 완화, Collision Monitor와 센서 기반 위치 추정을 사용하는 구조를 검토합니다. 단, 이번 Python 시뮬레이터를 Nav2 설치·실행 완료로 표시하지 않습니다.

T02 TX2 NX의 JetPack 4 계열은 Ubuntu 18.04 기반이며 NVIDIA는 JetPack 4.6.6을 해당 계열 최종 릴리스로 명시합니다. 최신 ROS2/Nav2가 그대로 설치된다고 가정하지 않습니다. 별도 지원되는 개발 PC 환경에서 통합 시험 후 T02의 OS·드라이버·연산 성능을 검토하고, T10 Orin 계열도 실제 JetPack에 맞는 ROS 배포판을 선택해야 합니다.

실물 적용에 필요한 순서: 센서/모터 드라이버 및 시각 보정 → 엔코더/IMU/거리 센서 동기화 → 지도 작성·위치 추정 → 저속 단독 이동 → 사람 추적 결합 → 장애물·낙하·통신 장애·손 접촉 정지 시험 → 승인된 환경에서 운용.

## 이번 실행 결과

가정·사무실 단독 이동 2개 모두 목표에 도착했습니다. 따라가기 2개는 대상 분실 시 정지 후 명시적 재개를 거쳐 최종 약 1.23m 간격을 유지했습니다. 네 시뮬레이션 모두 확장 격자 장애물 영역과 충돌하지 않았습니다. 주행 단위시험 12개와 교감-주행 중재 시험 2개를 통과했습니다. 이는 합성 지도와 센서 입력 결과이며 실물 성능이 아닙니다. 영상의 파란 원은 로봇, 초록 원은 선택 사용자, 분홍 사각형은 목적지입니다.
