# KR1-1101 대상 사용자·핵심 시나리오 R1

작성일: 2026-10-06 KST | Lumira KR1 Sprint1 | 수행: AI 설계·개발 초안

## 결과와 판정
사용자 2군과 3개 공통 시나리오를 설계했다. 아래 내용은 사용자 조사 결과가 아닌 검증할 제품 가설이다. R1 검토 전이므로 고객·기능 확정 판정은 보류한다. 기존 담당자 aijei IJ는 변경하지 않는다.

|사용자군|사용자와 구매자|환경·요구 가설|설계 반영|
|---|---|---|---|
|고령 성인|사용자 본인, 구매자는 본인/가족/기관 가능|시청각·디지털 숙련도 차이, 거실·침대 옆|큰 터치 목표, 음성+문자 병행, 느린 발화 선택, 설정을 돕는 사람과 권한 분리|
|성인 1인 가구|사용자와 구매자가 동일할 가능성|책상·거실, 야간 소음과 프라이버시 민감|음소거·카메라 상태 표시, 방해금지, 대화 종료 존중|

## SC-01 첫 사용·설정
1. 입력: 사용자가 전원을 켜고 가슴 화면에서 언어·글자 크기·음량을 선택한다. 기본 상태는 구동 DISARM.
2. 반응: 얼굴에 준비 상태, 가슴에 Wi-Fi/마이크/카메라 이용 목적과 선택 동의를 표시한다. 마이크·스피커 확인은 사용자가 시작한다.
3. 고령자 분기: 보호자 도움 모드를 선택할 수 있으나 로봇 소유자 권한을 자동 부여하지 않는다. 설정 완료를 음성·화면으로 함께 안내.
4. 1인 가구 분기: 야간 음량·프라이버시 모드 설정을 건너뛰거나 나중에 변경 가능.
5. 실패: Wi-Fi 실패 시 로컬 설정 유지, 네트워크 대화 불가를 표시. 동의 거부 시 외부 전송 없이 로컬 UI만 제공. 자동 팔/휠 동작 금지.
6. 수용 기준 제안: 설정 핵심 흐름 5분 이내, 도움 없이 완료 여부·오류·되돌리기 횟수 기록. 표본 검증 전 수치이며 실제 성공률은 미측정.

## SC-02 일상 대화·표정·제스처
1. 입력: 호출 또는 터치 후 사용자가 말을 건다. 예: 오늘 있었던 일을 이야기한다.
2. 반응: 듣기→처리→말하기 상태를 얼굴·가슴에 일치시킨다. 승인된 제스처 이름을 통해 낮은 진폭의 목/팔 표현을 요청한다. LLM 출력으로 모터 각도를 직접 실행하지 않는다.
3. 고령자 분기: 다시 말하기, 말 속도 낮추기, 자막을 같은 화면에서 제공.
4. 1인 가구 분기: 방해금지 중 선제 발화 억제. 사용자의 종료·중단 명령 우선.
5. 실패: 음성 불명확 시 1회 재질문 후 터치 입력 제공. 네트워크 중단 시 실패 표시·재시도 선택; 생성 대기 중 끝없는 처리 애니메이션 금지. 손상된 응답·오래된 제스처는 폐기.
6. 제안 시험: 첫 가시적 반응 1초 이내/응답 지연 p50·p95 측정, 대화중 끼어들기·스피커 재입력·팬/모터 소음을 포함. 음성 성능 합격값은 R2/R6 검토 후 고정.

## SC-03 도움 요청
1. 입력: 사용자가 도움이 필요하다고 말하거나 도움 버튼을 누른다.
2. 반응: 일상 기능 도움과 사람에게 연락하기를 구분해 확인 질문을 한다. 연락처·동의·연결 상태가 준비된 경우에만 수신자와 내용을 확인한다.
3. 고령자 분기: 큰 확인/취소 버튼과 음성 재확인. 1인 가구 분기: 등록 연락처 선택 및 전송 내용 최소화.
4. 실패: 연락처 미등록·망 단절이면 전송하지 못했다고 명확히 표시. 전송 완료/전달됨/읽음은 실제 확인된 상태만 표시. 위급 상황에서는 직접 주변 도움이나 지역 긴급전화 이용을 안내한다.
5. 이번 구현 범위: 흐름 설계와 모의 상태만. 실제 메시지 발송·긴급 서비스 연동 없음.
6. 검증: 미등록, 취소, 중복 요청, 타임아웃, 잘못된 수신자 조건에서 오발송 0건을 수용 기준으로 제안.

## 공통 범위·실패 대응
Stage1은 대화·얼굴 표정·가슴 터치·목/팔 동작, 장애물/추락 센서 기반 제한 이동 개발을 포함한다. 공간 자율주행/SLAM, 비구동 손가락의 물체 조작, 의료 진단, 긴급구조 보장, 무검증 책상 가장자리 자유 이동은 범위 밖이다. 책상 이동은 지그/낙하 방지 시험 통과 전 기본 비활성.

원문 대화/영상은 일반 진단 로그에 남기지 않는다. 동의 철회·음소거·카메라 중단과 대화 종료 경로를 제공한다. AI와 대화 중임을 숨기지 않는다.

## 평가 계획·미결정
고령 성인 5명 + 성인 1인 가구 5명은 초기 모집 제안이며 모집/인터뷰는 미수행. 각 시나리오의 완료·실패·도움 횟수·이해도·지연·불편 의견을 기록. 접근성 기준/표본/보상/연락 동의는 담당 검토 필요.
R1: 기능 범위 승인; R6: 접근성·시나리오; R2: 대화 실패 처리; R5: 설정/도움 UI. 실명 매핑 미확정. 제안 검토기한 2026-10-08, 확정 일정 아님.
