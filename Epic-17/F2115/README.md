# F2115: [F2115] 3D CAD Exterior 및 Packaging 설계

1. 부품 ID·revision·확인/추정 치수·고정/서비스 공간 정의
2. 개략 packaging/harness manifest와 CAD 오류 이슈표 작성
3. Onshape 오류 부품·중공/두께·간섭·공차 검증 계획
