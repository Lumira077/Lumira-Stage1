# F2105: [F2105] Stage1 제품 기능 Requirement 정의

Stage1 요구 기준을 대화·두 화면·자연스러운 표현·제한 이동·유선 충전으로 갱신한다.

1. 요구 ID·우선순위·입출력·오류·검증 방법과 HW 연결 정의
2. 대기/듣기/처리/말하기/음소거/오류/충전 UI 상태 구현
3. 네트워크 끊김·충전·음소거·추락·비상정지 조합 테스트
4. 제외 범위(SLAM·손가락·팔꿈치 구동)와 기준 revision 인계

검증: 로컬 상태 테스트는 실제 HW 안전 시험을 대체하지 않음

도구/개입: HW 이벤트/제어 API·전원 피드백; Python·브라우저

현재: 로컬 초안·디지털 산출물. 실제 고객/실물/양산 승인 미실시.
