# F2111: [F2111] 가슴 Touch LCD UI/UX

가슴 7인치 터치에 대화·음소거·음량·연결·충전 상태와 오류 복구를 배치한다.

1. 화면별 입력·피드백·상태·권한·삭제/동의 요구
2. 로컬 터치형 화면 및 안전 이벤트 시나리오 구현
3. 키보드/터치·중단·단절·에러·읽기 쉬운 상태 표시 시험
4. 화면·컴포넌트·문구·HW 연결 계약과 미결 API 인계

검증: 로컬 UI는 실제 음성/네트워크/충전 제어와 미연결

도구/개입: Figma 편집 접근·실제 터치 모듈·백엔드; 브라우저·PowerPoint

현재: 로컬 초안·디지털 산출물. 실제 고객/실물/양산 승인 미실시.
