# F2108: [F2108] 로봇 Size·비례·자세·동작 영역 설계

600mm 외형 기준으로 내부 부품·관절·하네스·작업 영역의 미결 치수를 추적한다.

1. 높이/폭/깊이·부품 외형·관절축·질량·무게중심 입력 양식
2. 전체 및 부위별 배치 그림과 확인/추정/미정 치수표 연결
3. 자세별 간섭·전도·시야·서비스·탁상 안전 검토 계획
4. 확정 치수와 추정 공간을 분리한 envelope revision 인계

검증: 폭·깊이·내부 공간·무게중심은 미실측; 400mm는 비교 가설

도구/개입: Onshape 오류 수정·SKU 도면·질량; Onshape·기구 계측

현재: 로컬 초안·디지털 산출물. 실제 고객/실물/양산 승인 미실시.
