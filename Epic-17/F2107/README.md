# F2107: [F2107] Human-Robot Interaction 기본 원칙 설계

대화 중 경청·종료 존중·감정 비단정·사용자 발화 우선의 HRI 원칙을 정의한다.

1. 상황별 음성·표정·제스처·프라이버시 규칙 정리
2. 대화 상태에 따른 표정/동작 제안과 중단 규칙 구현
3. 음소거·발화 중단·충전·위험 상태의 동작 억제 점검
4. 표현 매핑·예외·안전 우선순위를 제어팀에 전달

검증: 각도·속도·토크는 실물 시험 전 확정하지 않음

도구/개입: 모션/음성 이벤트·사용자 평가; Python·PowerPoint

현재: 로컬 초안·디지털 산출물. 실제 고객/실물/양산 승인 미실시.
