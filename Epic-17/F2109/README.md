# F2109: [F2109] 외관 Industrial Design Concept

기존 둥근 캐릭터 외형을 유지하며 화면·음향·통풍·서비스·하네스와 조화시킨다.

1. 외관 요구: 친근함·화면 가시성·접근·센서·흡배기
2. 기본 외장/색상 변형/액세서리 착용 대안을 비교
3. 표정·터치·센서·관절·서비스 접근이 가려지는지 검토
4. 정면/측면/후면 콘셉트와 변경 이유를 CMF/CAD에 전달

검증: 이미지 선호를 제조성이나 안전 적합으로 해석하지 않음

도구/개입: 디자인 선택·소재 샘플; PowerPoint·Onshape

현재: 로컬 초안·디지털 산출물. 실제 고객/실물/양산 승인 미실시.
