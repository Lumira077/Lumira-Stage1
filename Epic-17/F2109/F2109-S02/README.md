# F2109-S02 — [F2109-S02] 외관 Industrial Design Concept CAD·회로·Prototype 제작

상위: KR1-858. 기존 범위: 대안 A 기본 외장, B 동일 본체+의상, C 얼굴 스킨 차이. 모자/헤드폰/가방 체결 위치 가설.

실제 작성: 프로토타입 또는 설계 입력 작성. 검증/미결: 이미지 선호를 제조성이나 안전 적합으로 해석하지 않음. 필요: 디자인 선택·소재 샘플; PowerPoint·Onshape.

상태는 초안이며 실물·고객 시험·CAD·양산 승인 완료를 의미하지 않는다.
