# F2109-S03 — [F2109-S03] 외관 Industrial Design Concept Bench·통합·안전 시험

상위: KR1-858. 기존 범위: 사용자 선호와 가시성·센서/열·관절 간섭을 함께 평가. 그림을 제조 도면으로 취급하지 않음.

상태는 초안이며 실물·고객 시험·CAD·양산 승인 완료를 의미하지 않는다.
