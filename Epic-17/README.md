600mm는 기존 외형 참고, 내부 배치는 추정. 구체 CAD 설계는 다음 단계. 5mm 원본 보존, 3mm/2~2.5mm 경량화는 후보. 팔꿈치 고정·비구동손·2륜 소구역 이동·SLAM 제외·충전 연결 구동 억제. 모든 실물 안전·의료·인증·양산 적합성은 미검증.


현재 디자인 검토 도구는 PowerPoint입니다. PPT는 Epic KR1-832에 연결하며 과거 Figma 링크는 참고 자료로 유지합니다. 브라우저 데모는 작성했으나 Chromium 다운로드 실패로 화면 실행 검증을 완료하지 못했습니다.
