# F2104: [F2104] 제품 Concept 및 Target User 정의

대화 동반자 콘셉트와 고객·구매자 가설을 분리하고 고령자·성인 1인 가구의 필요를 검증한다.

1. 고객/구매자/환경/가치 가설과 근거 유형 및 조사 질문 정의
2. 경청형 캐릭터·쉬운 설정·사용자 통제 콘셉트 카드 작성
3. 첫 사용·일상 대화·설치성·구매 의향 인터뷰 과제 정의
4. 선정/보류 근거와 F2105·F2108·F2109 인계 목록 작성

검증: 실제 고객 인터뷰·구매자 검토 전 고객 확정 금지

도구/개입: 고객 모집·가격/운영비 근거; PowerPoint·Jira

현재: 로컬 초안·디지털 산출물. 실제 고객/실물/양산 승인 미실시.
