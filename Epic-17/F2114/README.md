# F2114: [F2114] CMF(Material/Color/Finish) 설계

외장 플라스틱과 유연 손의 소재·색상·마감 후보를 표면/세척/제조 조건과 연결한다.

1. 기본 5mm와 경량 후보·재료·세척·표면 요구
2. 몸체/머리/팔/손·그릴·버튼 소재/마감 매트릭스 작성
3. 샘플 청소·마찰·손촉감·음향·변색·접근성 시험 계획
4. 재료·색 코드·마감·증적·업체 승인 양식 인계

검증: 소재명만으로 강도·난연·피부 접촉 적합 판정 금지

도구/개입: 재료 샘플·공법·공급사 자료; Onshape·재료 시험

현재: 로컬 초안·디지털 산출물. 실제 고객/실물/양산 승인 미실시.
