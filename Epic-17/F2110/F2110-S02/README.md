# F2110-S02 — [F2110-S02] 얼굴 Display·표정 UX Design CAD·회로·Prototype 제작

SVG 캐릭터 표정과 상태 연동 화면 프로토타입 구현

상위: KR1-863. 기존 범위: 정적 표정 명세: 경청=중립 눈, 기쁨=미소, 오류=중립+상태, 충전=배터리 상태. 팩 교체 시 오류 기본 스킨 복귀.

실제 작성: 프로토타입 또는 설계 입력 작성. 검증/미결: 표정은 감정 진단이나 카메라 실제 작동 상태가 아님. 필요: 실제 얼굴 화면·렌더러·고객 평가; SVG·PowerPoint·브라우저.

상태는 초안이며 실물·고객 시험·CAD·양산 승인 완료를 의미하지 않는다.
