# F2110: [F2110] 얼굴 Display·표정 UX Design

얼굴 전용 화면에 대기·경청·처리·말하기·오류·음소거 표정과 상태를 분리한다.

1. 상태/표정/아이콘·기본 스킨·접근성 매핑 정의
2. SVG 캐릭터 표정과 상태 연동 화면 프로토타입 구현
3. 표정 의미·밝기·동작·오류 기본 스킨·가시성 확인
4. 자산 이름·매핑·버전·라이선스·복귀 정책 인계

검증: 표정은 감정 진단이나 카메라 실제 작동 상태가 아님

도구/개입: 실제 얼굴 화면·렌더러·고객 평가; SVG·PowerPoint·브라우저

현재: 로컬 초안·디지털 산출물. 실제 고객/실물/양산 승인 미실시.
