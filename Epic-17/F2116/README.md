# F2116: [F2116] Design Mock-up 제작

외형/UX 목업과 안전 구동 시제품을 구분하여 제작·평가 절차를 정의한다.

1. 외형/비구동/구동 목업별 목적·부품·위험·환경
2. 브라우저 UX 목업과 실제 크기 비구동 목업 제작 계획
3. 목업 조립·서비스·터치·하네스 및 실물 측정 양식
4. 목업 revision·사진·질량·결함·사용성 조건 인계

검증: 디지털 목업 완료가 실물 제작 완료가 아님

도구/개입: 제작 업체·재료·지그·안전 책임자; 브라우저·제작 도구

현재: 로컬 초안·디지털 산출물. 실제 고객/실물/양산 승인 미실시.
